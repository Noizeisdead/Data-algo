# Datastructuren en Algoritmen

Deze opdracht is gemaakt voor Datastructuren en Algoritmen. Hierin zijn verschillende datastructuren en algoritmen geïmplementeerd . Via een interface is het mogelijk om het data bestand om te zetten naar de verschillende structuren en de algoritmes hierop te gebruiken.

## Datastructuren
Stack: Een stack is een datastructuur die werkt volgens het principe Last In, First Out (LIFO). 
Linked List: Een linked list bestaat uit meerdere nodes. Elke node bevat een waarde en een verwijzing naar de volgende node. Hierdoor kunnen elementen gemakkelijk worden toegevoegd of verwijderd zonder dat de hele lijst verschoven hoeft te worden.
Binary Tree: Een binary tree is een boomstructuur waarbij elke node maximaal twee Children heeft: een linker- en een rechter-node.

## Algoritmen

Linear Search: zoekt een element door alle waarden één voor één te controleren. Dit algoritme is eenvoudig, maar minder efficiënt bij grote datasets.

Binary Search: halveert bij elke stap het zoekgebied, waardoor het sneller is dan linear search.
Stack Sort: is een sorteer algoritme waarbij gebruik wordt gemaakt van een stack.
Selection Sort: werkt door steeds het kleinste element uit het ongesorteerde deel te zoeken en dit op de juiste positie in de lijst te plaatsen.
